# Demo assets

Images for the trigger node's presentation mode (`python -m vision.trigger_node --visual-demo`):

| File | Shows |
|---|---|
| `img_2` | Open corridor (baseline, shown first) |
| `img_1` | Blocked corridor (boxes fallen, shown second) |

Any of `.jpg`, `.jpeg`, `.png` or `.webp` works, e.g. `img_1.jpg`. The feed is simulated: the images are displayed in sequence, not analyzed.
