FoGuard

in-browser

FoGuard watches a facility corridor for obstructions, keeps a verified map of which corridors are passable, and has an AI agent reroute deliveries around problems without ever approving a path that doesn't exist. Every feature built so far is listed with a plain-English explanation; use its "Try it" link to run it here.

Edge Vision Node Feed simulated incident

What the camera on corridor sees. Press Trigger Anomaly to simulate boxes falling: the feed switches, the corridor is blocked in the graph, the route is recalculated, and the Claude prompt is generated. The image always matches the graph: clear the corridor anywhere and the feed clears too.

The feed images aren't in docs/demo_assets/. Put img_1 and img_2 in demo_assets/ and run python scripts/build_dashboard.py.

    Live webcam mode (runs on your computer)
          
    The camera can't be driven from a web page. Run this in the project folder:
    
          
    python -m vision.trigger_node --webcam --verbose
    
          
    Presentation mode for judges (needs the two images in demo_assets/): python -m vision.trigger_node --visual-demo shows the open corridor, then the blocked one, then reports the obstruction.
    
          
    Step out of view until the overlay turns green, then put a person or object in the rectangle. Thresholds: people > 35% of the region, or scene change > 8%, for 3 readings in a row. Press C to recapture the empty corridor and Q to quit.

    MCP server
    
        
    The MCP server runs on the edge laptop and is published through ngrok; it's what Claude Web connects to. These buttons talk to it straight from this page, over MCP: they list its tools and read the live graph. Start it with python mcp_server.py --http --allowed-host YOUR-DOMAIN and run ngrok. To watch the real graph everywhere on this page, switch to Live edge (MCP) at the top.
